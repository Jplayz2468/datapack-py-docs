# datapack-py docs

  Documentation and examples for `datapack-py`.

  `datapack-py` lets you write Minecraft datapack logic in high-level Python instead of hand-writing
  messy function files. It is web-based, compileable, and built to make datapack development feel more
  like normal programming.

  The package code is not in this repository. This repo is for examples, guides, and reference docs.

  ## What is datapack-py?

  Minecraft datapacks are powerful, but the function files can get hard to read and maintain quickly.

  `datapack-py` gives you a cleaner Python layer on top of that. You write Python code, then compile it
  into the datapack function structure Minecraft expects.

  ## What is in this repo?

  - `examples/` - example projects and usage patterns
  - `docs/` - guides, notes, and reference pages
  - `README.md` - overview of the documentation repo

  ## Examples

  Check the `examples/` folder to see what datapack-py code looks like and what it compiles into.
